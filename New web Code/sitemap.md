# PDF Compressor Website Sitemap

**Website Type:** SaaS utility website (PDF tools)  
**Business/Project Name:** PDF Compressor  
**Core Features/Services:** Compress PDF, Merge PDF, Sign PDF, PDF Security, Contact/Support

## 1) Main Pages

- Home (`/`)
- Compress PDF (`/compress-pdf`)
- Merge PDF (`/merge-pdf`)
- Sign PDF (`/sign-pdf`)
- PDF Security (`/pdf-security`)
- Contact (`/contact`)
- API/Status (optional future)
- Legal (recommended future)
  - Privacy Policy (`/privacy-policy`)
  - Terms of Service (`/terms`)

## 2) Subpages and Content Structure

### Home (`/`)
- Hero section with primary CTA: **Compress PDF Now**
- Tool cards: Compress / Merge / Sign / Security
- Benefits section (fast, secure, browser-based)
- Testimonials/trust badges
- Secondary CTA to Contact

### Compress PDF (`/compress-pdf`)
- Upload area
- Compression level options
- Preview + download action
- FAQ block
- Internal links to Merge and Security tools

### Merge PDF (`/merge-pdf`)
- Multi-file upload area
- Reorder pages/files
- Merge action + output download
- FAQ block
- Internal links to Compress and Sign

### Sign PDF (`/sign-pdf`)
- Upload and signature placement flow
- Signature styles / draw / type
- Save and download
- FAQ block
- Internal links to Security and Contact

### PDF Security (`/pdf-security`)
- Password protect PDF
- Permission settings (print/copy/edit)
- Remove security flow (if enabled)
- FAQ block
- Internal links to Sign and Compress

### Contact (`/contact`)
- Contact form
- Support email / help details
- Response time expectations

## 3) Recommended User Flow

1. **Landing:** User enters from search or direct traffic to Home or a tool page.
2. **Tool Selection:** User clicks a primary task (most often Compress PDF).
3. **Task Completion:** Upload → Process → Download.
4. **Cross-Tool Navigation:** User discovers related tools through internal links.
5. **Support/Trust:** If blocked, user moves to Contact for help.

## 4) SEO-Friendly URL Structure

Use flat, descriptive, keyword-aligned paths:

- `/compress-pdf`
- `/merge-pdf`
- `/sign-pdf`
- `/pdf-security`
- `/contact`

### SEO Notes
- Keep one main intent keyword per page.
- Use unique title/meta description for each tool.
- Add internal links between related tools.
- Add FAQ schema to tool pages where possible.
- Add canonical tags to avoid duplicate URL variants.
